How do you want to play?

Claude writes the story from what you type. You can also try the game offline first.

Getting a key (a few minutes, once):

  1. Make an account at console.anthropic.com.
  2. Add some credit under Settings → Billing.
  3. Set a monthly spend limit under Settings → Limits, so the game can never cost more.
  4. Create a key under Settings → API keys, copy it and paste it below.

The game starts on Standard quality; Settings has Thrifty for less.

Remember keeps the key in this browser after it closes, where other files you open from this computer could read it. Unticked, it is forgotten when this tab closes.

    Quality

    Custom: your own models or effort (under Advanced).

    Advanced

    Keeps this session's last 200 bookkeeper turns in memory, for the Debug view's "Export bookkeeper turns" (labelling them for the event eval). Nothing is saved or sent.

    Effort

    The narrator writes the story. The parser reads what you type. The bookkeeper records what changed after each turn. The chronicle sums up the story once 16 turns have piled up, keeping the newest 6.

    Spending

    Game

    Brings this game up to the latest rules. It:

    • rewrites what people remember about you in the new short form;
    • adds places people told you about to the map;
    • sets the clock back if it ran ahead of the story;
    • fixes people the game made up so they match what the story says about them, and brings in the town's full cast, written by hand, folding anyone the game made up into the person they were;
    • fills in the lived-in town: everyone's age and history, the dead, the people who live elsewhere and the places people talk about;
    • gives the game its arc: the calendar, the council meeting, the ending and what loose ends still to come will cost;
    • gives what people remember about you its reasons: what kind of thing each memory was and how long it lasts, with how much they like you exactly as it was.

    About four API calls (none in the offline demo).

    When a game is brought up to "People who remember", the memories are first rewritten in the new short form (one call; off by default).
