# The documents, and which are current

Start at [CLAUDE.md](../CLAUDE.md) if you are a Claude Code session, at the
[README](../README.md) if you want to play.

## Live (kept true to the code)

- [README.md](../README.md): what the game is, privacy and cost, the
  five-minute quickstart, updating an older game (the rules table), links on.
- [MANUAL.md](MANUAL.md): everything the game does, for players: creation,
  places, the cast, people, the story's moving parts, Settings, commands.
- [MAINTAINING.md](MAINTAINING.md): saves and storage, updating, costs,
  editing the town and the game (`src/`), the tests and CI, the live-API
  checklist, the deliberate deviations from SPEC.md.
- [API_NOTES.md](API_NOTES.md): the Claude API wire format every call
  follows; edited only when the wire format changes.
- [CAST.md](CAST.md): the roster, generated by `node tests/cast-doc.cjs`
  (never edit by hand).
- [KNOWN_ISSUES.md](KNOWN_ISSUES.md): what needs the owner's key or
  decision, what waits on tuning, known rough edges, deferred refactors.
- [BUILD_PLAN.md](BUILD_PLAN.md), its contract and module sections:
  constraints, layout, the shared data contract, module responsibilities.
- [CHANGELOG.md](../CHANGELOG.md): what changed for players, per wave.

## Decision log
